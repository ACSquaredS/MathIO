# MathIO

Data input and output for [MathCraft](https://github.com/ACSquaredS/MathCraft), an open-source, MATLAB-inspired numerical computing environment.

> **Status:** Proposed. The repository is not created yet and implementation has not started.

## Role in MathCraft

MathIO reads data into MathCraft and writes results out. Other modules work on data that MathIO has already loaded.

## Depends on

- [MathCore](https://github.com/ACSquaredS/MathCore) for the array and matrix types

## Planned scope

- CSV reading and writing
- JSON reading and writing
- Binary formats for large numeric arrays
- Type inference and clear errors for malformed files

## Boundaries

File formats only. Data analysis belongs in the analysis modules.
